# 포켓몬스터 암브로시아 한글판

[Pokémon Ambrosia](https://github.com/AndrewC101/PokemonAmbrosia) v3.0.0(크리스탈 기반 GBC 롬핵)의 한국어 번역 패치와 공략 위키입니다.

- **위키**: https://welcome-to-nyc.github.io/pokemon-ambrosia-ko/
- **패치 받기**: [Releases](https://github.com/Welcome-to-NYC/pokemon-ambrosia-ko/releases/latest)의 `Pokemon_Ambrosia_v3.0.0_KO_patch.zip`

## 패치 적용

1. 원본 롬 `Pokémon Ambrosia (v3.0.0).gbc`를 준비합니다. SHA-1 `774a050873512532068343bfa59c7cebced4bfc8`
2. zip 안의 `.bps` 파일을 [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Flips로 원본 롬에 적용합니다.
3. 게임보이 컬러 에뮬레이터에서 새 게임으로 시작합니다.

이 저장소에는 롬 파일이 없습니다. 원본 롬은 직접 준비해야 합니다.
